# Lab Setup

## Objective

Build a Home SOC Lab for learning security monitoring, log analysis, alert investigation, and incident response using Wazuh.

## Environment

### Host Machine

* Intel i5-1335U
* 8 GB RAM
* Windows 11

### Virtual Machines

#### Kali-Attacker

* OS: Kali Linux
* RAM: 2 GB
* CPU: 2 Cores
* Purpose: Attack simulation and reconnaissance

#### SOC-Ubuntu

* OS: Ubuntu
* RAM: 4 GB
* CPU: 2 Cores
* Purpose: Security monitoring and investigation

## Planned Scenarios

1. Reconnaissance Detection (Nmap)
2. Brute Force Detection
3. File Integrity Monitoring Alerts
4. Authentication Monitoring
5. IOC Investigation
